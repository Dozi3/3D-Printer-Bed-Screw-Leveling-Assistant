# Security Policy

## Supported Versions

The `main` branch receives security and correctness fixes.

## Reporting A Vulnerability

Please do not publish suspected vulnerabilities as public issues before maintainers have had time to review them.

Report privately through GitHub Security Advisories when available, or contact the repository owner with:

- affected version or commit SHA
- steps to reproduce
- expected impact
- any relevant project file or mesh sample with personal data removed

## Scope

This is a local desktop utility. It should not require network access, credentials, telemetry, or printer-control permissions to run normal solver workflows.
